Hong et al. (2025) isoluminant JND ellipsoid grid (Hong, Bouhassira, Chow, Sanders, Shvartsman, Guan, Williams & Brainard)

modern dense JND ellipsoid grid (Wishart Process Psychophysical Model)

JND

Description

Dense per-subject JND ellipsoid field fitted via the Wishart Process Psychophysical Model from Hong et al. (eLife 2025). Eight color-normal observers completed ~12,000 trials each (mix of adaptive AEPsych + MOCS replications). The Wishart Process produces a SMOOTH 2-D field of 2x2 covariance matrices Σ(x, y) across the isoluminant plane (DKL-derived 2DW coordinates, range [-0.85, 0.85]). Each subject's fit is a 103×103 grid of Σ, providing a JND ellipsoid at every point — replacing MacAdam 1942's 25 ellipses with 10,609 per observer. This is the modern direct descendant of MacAdam 1942: fixes both of MacAdam's chief limitations — single observer + sparse sampling — and uses contemporary adaptive psychophysics + Bayesian smoothing.

Notes

  • ★ Each row gives a fitted ellipsoid as both the raw 2x2 covariance (sigma_xx, sigma_xy, sigma_yy) and the derived ellipse semi-axes (a, b) plus rotation theta_deg. Both representations are equivalent.
  • Grid coordinates (x, y) are in DKL-derived 2DW units, NOT CIELAB. Use the calibration matrices in raw/ (M_2DWToRGB, M_2DWToDKLPlane) to map to RGB or DKL.
  • Wishart Process smoothing means adjacent grid points are not independent. Don't treat the 84,872 ellipses as 84,872 independent measurements; effective DOF per subject ≈ ~100.
  • Bootstrap iterations (120 per grid point) are NOT included in this canonical export to keep size reasonable. The original Zenodo CSV has all 120 bootstraps if you need confidence intervals.
  • ★ This is the gold-standard JND dataset published in the project's diagnostic era; supersedes MacAdam 1942 for isoluminant JND evaluation. MacAdam 1942 remains in the pool for historical comparison only.
