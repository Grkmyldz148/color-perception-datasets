Notes

  • Original tristimulus values in the paper are scaled (e.g., 2871 represents X=0.2871). I've preserved the conventional decimal form.
  • Munsell mean hues use original Bartleson notation (e.g., '6.81R' = 6.81 in the Red sector). Some implementations expect 'R6.81' instead.
  • Sigma values are for Illuminant A specifications only (per original Table I); not separately reported for Illuminant C.
