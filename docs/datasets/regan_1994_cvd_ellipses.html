Datasets / regan_1994_cvd_ellipses

Regan, Reffin & Mollon (1994) CVD discrimination ellipses (Cambridge Colour Test)

Description

The first REAL colour-vision-deficient observer discrimination data in this pool. 27 observers — 5 normal, 1 protanope, 4 protanomalous (1 extreme), 2 deuteranopes, 2 extreme + 12 deuteranomalous, 1 tritanope (both eyes) — each with up to 3 full discrimination ellipses measured by the luminance- noise Cambridge Colour Test on the CIE u'v' isoluminant plane. Each ellipse: centre (Table 1, xy 1931 + u'v' 1976), long-axis length (u'v' units), axis ratio (long/short), orientation angle. CVD ellipses are hugely elongated (axis ratio up to 20) along each defect's confusion axis (protan ~178/2 deg, deutan ~165, tritan ~90) — the MacAdam-ellipse analogue for colour deficiency.
